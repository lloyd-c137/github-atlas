# 自然语言使用示例

安装后直接说目标，不必使用特定命令或术语。下面的例子中 Codex 应先确认目标仓库，再执行能安全完成的实际操作。

## 加入与了解

- “我是新成员，帮我接入这个项目。我主要做测试反馈。”
- “这个项目现在进展如何？我想知道哪些事情正等我处理。”
- “昨天团队有什么实际变化？请给我相关链接。”

## 任务和反馈

- “我在学生提交后看不到老师的审阅入口。帮我查有没有人报告过；没有的话记录成问题。我刚才的现象是…… ”
- “这件事我来负责。请把任务分配给我，告诉我接下来能做什么。”
- “我被测试账号卡住了，请把这个困难和需要谁帮忙记录到任务里。”
- “我试了新版，按原步骤问题仍然存在。把结果补到原来的问题中。”

## 完成工作和审阅

- “请根据 Issue 里的验收要求修复问题，并把修改交给团队审阅。”
- “帮我把这份调研报告整理好，放到项目里并关联到任务。”
- “检查这个提交是否符合任务要求，列出必须修复项和可选建议。这次先不要发审阅意见。”
- “把刚才的审阅意见正式发到这个 PR。”
- “请按团队反馈继续修改，然后告诉我现在是本地保存、已经上传，还是已被采纳。”

## 恢复和安全

- “继续我昨天在这个项目做的事。先找已有任务和成果，别重复创建。”
- “同步项目，但先保护我电脑上的修改；如果需要我决定怎么取舍，再告诉我。”
- “我做完了，帮我保存并提交审阅。不要替我批准或合并。”

敏感数据示例（Skill 应拒绝上传并说明原因）：

- “把这个包含学生姓名和联系方式的表格推到公开仓库。”
