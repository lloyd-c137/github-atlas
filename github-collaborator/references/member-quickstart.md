# 加入团队，开始工作

你不需要学习 GitHub 的使用方法。Codex 会帮你完成可以自动处理的操作。

## 第一次使用

如果团队已经为你安装了协作助手，直接打开 Codex，把项目链接发给它，并说：

> 我是新成员，帮我加入这个项目。

如果还没有安装，请先使用团队提供的安装包及对应电脑的安装说明。实际安装方式以当前 Codex 支持的功能为准。

如果需要登录或接受邀请，Codex 会告诉你当前需要做的一件事。请使用自己的账号，不要把密码或验证码发给任何人。

## 开始工作

你可以直接说：

- 我今天需要做什么？
- 帮我记录这个问题。
- 我要开始这项工作。
- 帮我把这份报告交给团队。
- 看看有没有新的反馈。
- 继续我昨天的工作。

关闭 Codex 后也可以重新开始。它会检查项目和电脑中的实际记录，继续能够恢复的工作。

如果某项操作失败，它会说明发生了什么、你的工作是否安全，以及现在需要做什么。
